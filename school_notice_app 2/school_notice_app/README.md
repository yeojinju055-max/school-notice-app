# 몽글알림장 (Flask)

학교 공지·수행평가·선생님 페이지를 한곳에 모아보는 웹사이트입니다.

## 1. 실행 방법

```bash
# 1) 필요한 패키지 설치
pip install -r requirements.txt

# 2) 실행
python app.py
```

실행 후 브라우저에서 `http://127.0.0.1:5000` 접속.
처음 실행하면 `notice.db` 라는 파일이 자동으로 생성되는데, 이게 우리 데이터가
저장되는 SQLite 데이터베이스입니다. 확인용 샘플 공지 3개도 자동으로 들어갑니다.

## 3. 기능별 코드 설명 (세특 작성 시 참고)

### 🔐 로그인 / 회원가입
- 별도 라이브러리 없이 Flask의 `session`으로 로그인 상태를 직접 관리합니다.
  로그인에 성공하면 `session['user_id']`에 사용자 id를 저장하고, 로그아웃하면
  `session.clear()`로 지웁니다.
- 비밀번호는 절대 그대로 저장하지 않고, `werkzeug.security.generate_password_hash`로
  **해시**해서 저장합니다. (DB가 유출돼도 원래 비밀번호를 알 수 없게 하기 위함)
- `login_required`라는 함수를 직접 만들어 데코레이터로 사용했습니다. 이 데코레이터가
  붙은 페이지는 로그인 안 하면 자동으로 로그인 화면으로 보내집니다.

### 🗂 공지 분류
- 공지마다 `category`(학사/행사/생활 등) 값을 저장해두고, 메인 페이지에서 그 값을
  기준으로 필터링합니다.
- 지금 버전은 사람이 카테고리를 직접 정해서 저장하는 방식입니다. AI가 글 내용을
  분석해서 자동으로 분류해주는 기능은 아직 없고, 다음 단계로 시도해볼 만한
  확장 포인트입니다 (예: 제목·내용에 특정 키워드가 있으면 자동으로 분류하는
  규칙 기반 방식부터 시작).

### 🔍 검색 기능
- `index()` 함수에서 SQL의 `LIKE` 구문을 사용해 제목이나 내용에 검색어가 포함된
  공지만 걸러냅니다.
- `WHERE title LIKE '%검색어%' OR content LIKE '%검색어%'` 형태의 쿼리이며,
  분류 필터와 동시에 적용할 수 있게 조건을 이어붙이는 방식으로 짰습니다.

### 🗓 일정 관리 (미완성)
- 수행평가 마감일을 캘린더 형태로 보여주는 기능을 시도했으나, 완성하지 못했습니다.
- 막혔던 지점:
  1. 지금까지 만든 기능은 "글 하나 = 화면에 한 줄"로 단순 대응되는 구조였는데,
     캘린더는 "같은 날짜에 여러 일정이 몰릴 수 있는" 구조라서 데이터를 날짜별로
     묶어서(group) 다시 정리해야 함
  2. Flask만으로는 화면에 달력 모양을 그리기 어려워서, JavaScript 캘린더
     라이브러리(FullCalendar 등)와 데이터를 주고받는 방식(API처럼 JSON으로
     응답하기)에 대한 이해가 추가로 필요함
- 이 경험을 통해 AI가 짜준 코드를 그대로 붙여넣는 것과, 실제로 왜 그렇게 짜야
  하는지 이해하는 것은 다르다는 걸 느꼈고, Flask의 요청-응답 흐름과 데이터베이스
  다루는 법을 더 공부한 뒤 다시 시도해볼 계획입니다.
